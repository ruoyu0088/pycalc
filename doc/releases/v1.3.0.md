# PyCalc v1.3.0

## At a glance

PyCalc v1.3.0 focuses on AI-assisted workflows and richer notebook-style output. It adds an offline AI Prompt Helper dialog for building context-aware prompts and extracting runnable Python code from AI replies, introduces a built-in `display()` function for rich mid-cell outputs (formulas, arrays, DataFrames, Matplotlib and Plotly figures), adds a clipboard Paste button beside the editor's Clear button, and moves the theme switch into Display Settings.

## What changed since v1.2.0

### Built-in `display()` function

- Added `display(*objs)` as a Python built-in (`builtins.display`), available across all sessions, resets, and user-defined functions without cluttering the Variables or Functions sidebar tables or session snapshots.
- `display()` reuses the exact formatting pipeline as the final expression of a cell:
  - SymPy expressions and equations render with MathML / All-Math / plain text according to Display Settings.
  - NumPy arrays and pandas/Polars DataFrames render with Pretty / Table views and float precision settings.
  - Plotly `Figure` objects render as interactive charts anywhere in a cell, not only on the last line.
  - Matplotlib `Figure` objects are captured as PNG images in place and closed automatically to avoid duplicate output.
- Multiple `display()` calls per cell (and calls executed before a later exception) are preserved in order, persisted in IndexedDB history, and re-rendered when Display Settings or the theme change.
- Added `display` to editor autocomplete, signature hints, and the mobile Functions drawer.

### AI Prompt Helper & topbar layout

- Moved the light/dark theme toggle from the topbar into the Display Settings dialog (`#display-dialog`), keeping live updates across the UI, CodeMirror, Matplotlib defaults, and Plotly charts.
- Added an **AI Prompt Helper** button in the topbar opening a focused dialog without exposing the long prompt template in the input area:
  - Assembles a localized prompt matching the active UI language (`zh` / `en` / `ja`) with runtime version, built-in Math/`ans`/`display()` notes, auto-imported library aliases, installed optional libraries, Matplotlib/Plotly rules, and single-code-block output instructions.
  - Lets users choose history scope (**None**, **Recent N entries**, or **All history**), and toggle including history outputs, current editor input, and current session variables/functions (preferences persist in IndexedDB).
  - Provides one-click **Copy Prompt**, a **Paste** button for AI replies, and **Extract code to editor** to pull Python fenced blocks cleanly into the editor (ignoring non-Python output blocks) and close the dialog.
- Raised toast notifications above modal dialogs with `pointer-events: none` so feedback stays visible and never intercepts clicks.

### Editor clipboard paste

- Added a **Paste** icon button (`#editor-paste`) right next to the **Clear** button above the code editor.
- Pastes clipboard text directly at the current cursor position (or replaces the active selection), normalizes `CRLF`/`CR` line endings to `LF`, and shows localized feedback when the clipboard is empty or unavailable.

### Release engineering & testing

- Updated the repository screenshot in the READMEs.
- Bumped the application version to `1.3.0`.
- Expanded unit tests (35 tests) and browser acceptance checks to cover clipboard paste, Display Settings theme switching, AI Prompt assembly and code extraction, and built-in `display()` formatting and persistence.

## Installation

Download `pycalc-v1.3.0-html.zip` from the release assets, extract `pycalc.html`, and open it in a modern browser. The file works through `file://` and makes no network requests at runtime.

The full build contains NumPy, SymPy, Matplotlib, Polars, pandas, and Plotly. It is approximately 79 MiB; first launch can take a little longer while the browser initializes the inlined Pyodide runtime.

## Notes and limitations

- Browser clipboard read (`Paste` button) uses `navigator.clipboard.readText()` and may prompt for permission or be restricted in insecure contexts depending on the browser.
- Plotly charts can now be displayed either via `display(fig)` or as the final expression of a cell; avoid calling `fig.show()`, which returns `None`.
- Session data remains local to the browser profile and origin.
- Validation for this release: 35 unit tests passed, plus headless Chrome end-to-end verification for paste, theme switching in Display Settings, AI Prompt helper, and built-in `display()` (including SymPy equations, NumPy/Polars tables, Matplotlib figures, Plotly 3D surfaces, and reload persistence).
