# PyCalc v1.2.0

## At a glance

PyCalc v1.2.0 is a major UI and extensibility release. It adds a generic pipeline for embedding pure-Python PyPI packages, first-class Plotly support with interactive charts, a redesigned mobile/desktop workspace, variable and snippet authoring, console editing tools, and an automated GitHub Release workflow.

This release includes 19 feature commits since `v.1.1.1`.

## What changed since v.1.1.1

### Plotly and pure-Python packages

- Added a generic build path for packages that are not in the Pyodide lock but ship a `py3-none-any` wheel.
- The build resolves PyPI metadata and dependencies, verifies SHA-256 hashes, caches wheels, and injects synthetic entries into the embedded Pyodide lock.
- Added Plotly 7.1.0 support. Its wheel and the bundled Plotly.js 4.1.1 are inlined into the generated HTML, so charts remain fully offline.
- Added the `px = plotly.express` build alias. Selected library chips such as `px` are imported automatically at startup.
- A returned `plotly.graph_objects.Figure` is rendered as an interactive chart instead of its text representation. Charts support pan, zoom, hover, modebar actions, and session restore.
- Plotly charts use the full available mobile width, automatically expand axis margins for labels, and follow the active dark/light UI theme.
- Added Plotly to the GitHub Pages build and documented the workflow in all three READMEs.

### Workspace and mobile UI

- Replaced the remaining textual toolbar labels with consistent inline SVG icons.
- Moved the run button beside the editor and removed the separate run-key row, freeing vertical space on phones.
- Added a collapsed virtual-keyboard mode on desktop, with a control to expand or collapse it.
- Made the mobile sidebar full-width and added a close control to the Variables panel.
- Wrapped long variable values onto a second row and improved the Functions column ratio.
- Added a variable creation dialog for strings, arrays, and DataFrames.
- Variable definitions can be executed as Python code when the dialog is submitted.
- Added a shared snippets list, snippet type selection in the add dialog, and an edit/delete dialog for existing snippets.
- Clicking a variable or function in the sidebar inserts its name into the editor and closes the mobile sidebar.

### Console and editor

- Added a context menu to history prompts with copy and delete actions.
- Console input can be inserted into the editor as a separate input block.
- Kept the existing optional prompt display, keyboard layouts, and mobile keyboard controls.

### Build, launcher, and release engineering

- Bumped the application version to 1.2.0.
- Updated the Windows `start.bat` launcher to find Python on `PATH` and invoke it with `call`, so a local `python.bat` wrapper works correctly.
- Added `v*` tag-driven GitHub Release automation. The workflow builds the full single-file HTML, packages it as a ZIP, and attaches it to the tag's release.
- The GitHub Pages workflow is unchanged.

## Installation

Download `pycalc-v1.2.0-html.zip` from the release assets, extract `pycalc.html`, and open it in a modern browser. The file works through `file://` and makes no network requests at runtime.

The full build contains NumPy, SymPy, Matplotlib, Polars, pandas, and Plotly. It is approximately 79 MiB; first launch can take a little longer while the browser initializes the inlined Pyodide runtime.

## Notes and limitations

- Only pure-Python wheels can be added through this pipeline. Packages with native extensions still require an official Pyodide build.
- Plotly charts must be the final expression of a cell. Use `fig` on the last line rather than `fig.show()`, which returns no figure.
- Interactive chart state is restored from the saved figure specification; arbitrary Python objects inside a figure cannot always be serialized.
- Session data remains local to the browser profile and the HTML file location.
- Validation for this release: 32 unit tests passed, and the full browser acceptance suite passed.
